# Murdoku Assistant（谋杀数独 · 做题网页）

一个还原 [Murdoku](https://murdoku.com)「数独 + 谋杀推理」做题体验的纯前端网页：阅读嫌疑人线索，把所有人放到犯罪现场网格上，系统对照官方答案校验，**所有人位置全部正确即破案**。

- 零依赖、零构建，双击 `index.html` 即可在浏览器打开，桌面 / 手机自适应。
- 内置官方真实入门案件 **Car Repair（6×6，VERY EASY）**，数据来自官网免费可打印谜题，答案以官方答案页为准。

## 玩法

1. 每行、每列只能有一个人；放下一个人后会锁定其整行整列。
2. 根据每个人的线索（在某房间 / 坐在椅子上 / 在油渍上 / 在置物架旁 / 独自在某区域……）推理位置。
3. 深色物件（桌子、电视、置物架、盆栽）不可站人；椅子、油渍、车可以站。
4. 用「✕ 标记」给当前选中的人打草稿叉；点棋盘上的棋子可收回重放。
5. 点「检查」：位置不对处标红；六人全部正确即破案。

## 目录结构

```
index.html        页面骨架
css/style.css     noir 案卷风样式（房间墙、区域铭牌、物件、棋子）
js/cases.js       案件数据（房间 / 物件 / 人物 / 线索 / 官方答案）
js/app.js         做题交互（放置、行列封锁、X、撤销、检查）
js/engine.js      逻辑引擎（可选，当前做题页未引用）
```
