MURDOKU LOCAL — 正式寻宝赛题 / 原站风格离线播放器

启动
直接打开 index.html；已打开的页面刷新即可载入本次更新。
也可双击 START.cmd 启动 http://127.0.0.1:4173（需要 Node.js）。
字体、图片、地图和原始 PDF 全部在文件夹内，游玩不需要联网。
同一进度请继续使用同一浏览器和地址；file: 与 127.0.0.1 的存档独立。

正式赛题
默认打开 The Treasure Hunt（24×24），来自用户提供的
murdoku-contest1-treasurehunt-EN.pdf。
包含 23 位海盗、宝藏、17 个区域、英文原文及中文译文。
地图直接采用 PDF 原图；头像由原始矢量画作提取，帽子和眼罩细节保留。
落位人物显示无边框头像及左上角字母；手动和自动排除使用原站粗黑 X。
原始 PDF 可在 设置 → 本地文件 → 查看 PDF 中对照。
没有官方答案或逐步提示；检查按钮核对录入规则，不声称通过官方答案验证。

宝藏
放置 23 位海盗之后，最后剩余的行和列交点为宝藏位置。
点击右侧 Treasure / 宝藏，再点击格子；也可按 T 后点击。
宝藏允许放在普通人物不能占据的物品格上，并参与行列唯一性检查。
右侧按钮和规则检查弹窗会显示宝藏坐标（R 为行，C 为列，从 1 开始）。
每艘船各为一个独立区域；床和吊床所占的两个格子都可放人。
门两边正对门的两个格子都算门前。相邻不包含斜角。
Nehemiah 的“在水域、船旁边”按水域格与船格正交相邻检查。

游玩
选择头像，单击格子增删小写候选；长按格子落位 / 移除人物。
按 2 切换直接落位，按 1 返回候选。拖动可连续添加或删除候选 / X。
橡皮擦清空单格；长按橡皮擦清空棋盘，支持撤销。
自动 X 随人物位置排除所在行列，不会永久删除原有候选。
点击证词划除 / 恢复；悬停粗体关键词高亮区域、物品或人物。
点击左上角返回箭头切换题目，正式题与原有练习题进度独立保存。
24 张人物卡在较矮窗口中可滚动；放大地图后按 H 拖动平移。

快捷键
1 候选；2 落位；X 排除；E 擦除；M 符号；T 宝藏 / 目标；H 平移。
方向键移动焦点；空格执行工具；Enter 落位；Delete 清空。
Ctrl+Z 撤销；Ctrl+Y / Ctrl+Shift+Z 重做；[ / ] 切换人物。
P 暂停；/ 搜索；? 帮助；+ / - 缩放；Ctrl+滚轮缩放。
Alt+点击格子写笔记；双击头像定位已放置的人物。

设置和本地功能
语言、深色、音效、计时、候选 / 落位、头像 / 列表、关键词高亮、自动 X、
坐标、X 大小、缩放、撤销 / 重做、打印等功能可用。
正式题保留 PDF 地形、物品、边界和区域名称的原始外观，相应样式选项禁用。
高尔夫与演示题仍可调整地板、物品和区域标签等样式。
设置 → 本地文件：PDF 对照、JSON 导入、存档导出、笔记、检查点、搜索、
规则检查、玩法、打印、重开等。PDF 导入用于对照阅读，不自动转换题目。

存档
浏览器自动保存。可导出包含题目数据、棋盘、笔记、检查点和历史的 JSON。
迁移电脑时复制整个 murdoku-local 文件夹（包括 assets），再导入存档。
存档内的素材路径指向这个文件夹，不会将全部图片和 PDF 重复嵌入 JSON。
自行导入的 PDF 附件请另行保留；清除浏览器数据会清除本机进度。
官网账号同步、排行榜、购买和正式比赛提交仍在官网进行。

内置题目
1. The Treasure Hunt，24×24，正式比赛 PDF，无官方答案。
2. The Golf Course，16×16，官网公开练习题，含其原站提示和答案。
3. 玻璃花房的访客，8×8，原创演示题，含答案。
4. 比赛操作模板，24×24，保留为空白导入模板，不是正式题。

文件
index.html / styles.css / app.js：界面、交互与本机存储。
engine.js：题目校验、规则检查。
contest-data.js / contest-puzzle.json：正式题数据（相同内容）。
CONTEST-DATA-AUDIT.txt：逐格区域和物品转录记录。
data.js / golf-data.js：原有演示、模板和公开练习题。
assets/contest-original.pdf：用户提供的 PDF 原件副本。
assets/：本地素材；署名见 assets/CREDITS.txt。
DATA-FORMAT.txt：数据格式。VALIDATION.txt：检查记录。
